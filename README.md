# Расчёт срока заказа FDM-печати

Модель перебирает назначения партий на совместимые принтеры и проверяет, что один оператор успевает подготовить аппарат и снять деталь. Срок заказа определяется по снятию последней партии.

Для запуска нужен Python 3.12. В корне репозитория выполните:

```sh
python calculate.py
python proverka-polzy-20261117.py
python two_batches.py
```

В первых двух учебных очередях полный перебор и правило ближайшей готовности дают одинаковые сроки — 460 и 450 минут. В примере с двумя новыми партиями одна из них совместима только с первым принтером. Закрепление первой партии за самым быстрым для неё аппаратом даёт 125 минут до готовности комплекта, совместный выбор — 75 минут. Ранее принятый заказ в обоих случаях готов на 15-й минуте. Это расчёты на заданных параметрах. Исходные данные и результаты первых двух случаев лежат в `parameters.json` и `results.json`.
